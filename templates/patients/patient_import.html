How it works

  1. Download the template (button above). It is a spreadsheet with the right column names and one made-up example patient.
  2. Open it in Excel or Google Sheets. Keep the first row as it is. Delete the example patient and type your patients underneath: one row per patient.
  3. Only three things are needed for each patient: full name, sex and mobile number. Leave a cell empty if you don't know it.
  4. Save it as “CSV UTF-8”. In Excel: File › Save As › CSV UTF-8 (Comma delimited). In Google Sheets: File › Download › Comma-separated values.
  5. Upload the file below. We check every row first. If anything needs fixing, nothing is imported and you get a list of the rows to correct, so you never end up with half a register.
